SplitGBA

UP TO 4 FRIENDS. ONE SCREEN.

Split screen couch multiplayer for the Game Boy Advance. Bring the controllers, pile onto the sofa and play together like it is 2004: race the same save, explore side by side, trade when you need to.

▶ PRESS START
Download macOS Windows Linux

macOS (Apple Silicon and Intel) · Windows 64-bit installer or portable · Linux AppImage or tar.gz. Fully self contained, nothing else to install.

// BUILT FOR GAME NIGHT

Everything you need to put four Game Boys on one television, and nothing you don't.

1 to 4 players, one screen

Frame perfect split screen. Xbox, PlayStation, Switch Pro and 8BitDo pads work out of the box: hotplug them or assign per player in the menu. Player 1 can use the keyboard.

Link cable built in

All instances share an emulated 4 player link bus. Trading and battling work exactly like on hardware, with live link status in the HUD.

Race mode

One hotkey resets every game in sync. A stopwatch or countdown runs big on screen. Who gets furthest in 30 minutes?

Global speed 1x to 4x

One key press fast forwards everyone at once. Grinding gets bearable and nobody can secretly speed ahead.

Save states for all

F5 snapshots all four games at the same moment, F9 restores them. Separate cartridge saves per player, even with one shared ROM.

English and German

Launcher, menus and the controls overview ship in English by default and switch to German live from the settings. Everything persists.

// LINK GUIDE

The link behaves exactly like the real 4 player adapter, including its one golden rule.

  • Player 1 must take part in every trade or battle. Just like the parent unit on real hardware, only player 1 clocks the bus. The HUD shows live who is in link mode and warns when player 1 is missing.
  • Both players walk into the in game Cable Club (upstairs in any Pokémon Center) at the same time.
  • Switch to 1x speed for trades. The cleanest setup is launching just the two participants.
  • Generation 3 rules still apply: FireRed and LeafGreen need the National Dex to trade with Ruby, Sapphire or Emerald.

// GET STARTED

No dependencies and no setup wizard. Download, drop your ROMs, play.

STEP 1

Download and install

Grab the latest release for your platform. On macOS: right click, then Open on first launch (unsigned open source app).

STEP 2

Add your games

Put .gba files dumped from your own cartridges into a roms/ folder or SplitGBA/ in your home directory.

STEP 3

Press start

The launcher opens automatically: pick games, set the player count, plug in controllers, go. Press F for fullscreen on the TV.

# prefer building from source?
git clone --recursive https://github.com/JosipFX/splitgba.git
cd splitgba
./build.sh
./build/splitgba   # opens the launcher
