Multiplayer,
without the clutter.

Everything required to turn one TV into four Game Boys. SplitEmu keeps every player visible, every controller separate and every session in sync.

01 / DISPLAY

One screen. Four adventures.

Frame-perfect layouts adapt automatically from solo play to a full 2×2 grid. Every player keeps a crisp viewport and their own save.

02 / LINK

Link cable built in.

Trade and battle on the emulated four-player link bus, with live connection status directly in the HUD.

03 / RACE

Race mode, ready.

Reset all games in sync, start a stopwatch or set a countdown. The empty quadrant becomes the timer in three-player mode.

04 / CONTROL

One tempo. Fair for everyone.

Speed up every instance together from 1× to 4×, snapshot all four games at the same moment and restore the complete session with one key.

Link guide

Real link rules.
No extra cables.

The connection behaves like the original four-player adapter. That includes one important rule:

  1. Player 1 must join every trade or battle. As the parent device, P1 clocks the entire bus.
  2. Enter the in-game Cable Club together and switch back to 1× speed for the cleanest connection.
  3. Original game compatibility still applies. SplitEmu does not bypass Generation 3 trading rules.
Start a session

From download
to game night.

No account, no setup wizard and no bundled games. Download the app, add ROM dumps from cartridges you own and press start.

STEP 01

Download SplitEmu

Grab the latest release for macOS, Windows or Linux.

STEP 02

Add your games

Place your own .gba dumps in a roms/ folder or choose them directly in the launcher.

STEP 03

Plug in and play

Connect controllers, choose the player count and go fullscreen on the TV. Xbox, PlayStation, Switch Pro and 8BitDo are supported.

build from sourcebash
$ git clone --recursive https://github.com/JosipFX/splitemu.git
$ cd splitemu && ./build.sh
$ ./build/splitemu

Good to know

SplitEmu ships no games and downloads none. Use only ROM files dumped from cartridges you own.
